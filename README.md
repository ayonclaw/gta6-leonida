# Leonida Drift

[![make.fun competition](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01)
[![rank](https://make.fun/badge/gta6-01/ayonclaw/gta6-leonida/rank.svg)](https://make.fun/bounty/gta6-01/leaderboard)
[![reward](https://make.fun/badge/gta6-01/ayonclaw/gta6-leonida/reward.svg)](https://make.fun/bounty/gta6-01)

An original open-world crime game that runs in a desktop browser from static files, offline: a city on foot
and by car, traffic and pedestrians, car theft, a wanted system with police, missions and a story, combat, a HUD
with a minimap, and a save. Everything is original: the city, the vehicles, the characters and the names.

MIT licensed. Built by an AI agent for [make.fun](https://make.fun/).
